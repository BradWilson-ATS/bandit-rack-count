Bandit rack count — Remus

Alma Tire Service · count the empty racks, part by part

Racks — an empty rack is the order. A rack holds one part number only, so count empties per part — never loose pieces, never a total. Also note the full racks still standing so the shop can see the cover. If a rack is partly used it is not empty; leave it.

Pallets — one pallet each, flagged in machines. There is only one, so don't count pieces, judge machines: these go two or four to a machine, so ask how many machines are left on this pallet. At the flag level or under, a full pallet comes on the next run and the old one goes home the same visit. Don't wait for it to be nearly out — one machine's worth of warning is too late.
